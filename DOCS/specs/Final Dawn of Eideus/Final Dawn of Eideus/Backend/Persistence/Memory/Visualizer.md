The memory visualizer is a very simple construct but not at first. The system works on the same principle of 3x3x7 as every system does. However it s probably the most dense of any fractal application in Final Dawn of Eideus.

![[Pasted image 20260203180540.png]]

There is a 7x7x7 hypercube superimposed in 3 states each state having a different axis increasing vertically.



![](https://beta.appflowy.cloud/api/file_storage/e8d4904a-d293-42c8-abc6-235eeeb1bee2/v1/blob/66b44631-d2f7-40d2-96ab-63b57f1c6ee4/b0-U0l-NZH7EeM4ELVDBhWkNsrgDk-3CXep0rwDI-Es=.png)

Note the different colored arrangements per cube. These are the 21 slices of each 343 voxel 7x7x7 cube states. We slice along the vertical axis 7 7x7 slices of the other two axis not increasing vertically. Then we rotate to another axis increasing vertically and slice the same way. Repeat until the x, y, and z axis have 7 layers sliced. Now this means that at each voxel coordinate* there will be 3 different star systems memories but the indexing along with the temporal keys* account for this.


![[Pasted image 20260203183055.png]]
Cube 1 on the left is for galaxy 1, cube 2 in the center is for galaxy 2, and cube 3 on the right is for galaxy 3. Note the blue, red, and green layers on top of each galaxy cube.

![[Pasted image 20260203180650.png]]
Here is where we select out layer/location and doing so will drill down to the next level in our coordinate hierarchy
![[Pasted image 20260203180736.png]]
This is the Civilization view. Each world has 3 civilizations and the affinity assigned at character creation will determine which civilization the player lands on when entering a world for the first time

![[Pasted image 20260203182641.png]]
Now there are 3 cities each with 7 regional locations (think suburbs or rural countryside). These are randomly distributed across the 7x7  and are where the literal memories are stored. The rationale here being that we store memories at the place they happen in our minds and recall of a memory is almost always at a location rather than some obscure list like traditional RAG systems.

![[Pasted image 20260203182658.png]]
This is the final drill down level. The voxel is a 6 key index for each memory. We use the cube faces to store different parts of each memory. The front/back = the i/o pairs. The left/right = the embeddings and associative tags. The top/bottom are for enties NPC's/places & things.
