

- Core: 2 soft/basic skills = **(Attack skill, core-affinity)** + **(Buff skill, core-affinity, counters core weakness)**
    
- Sub: 2 skills = **one neutral** vs sub affinity, **one weak** vs sub affinity
    
- Cross: 2 skills = **one neutral**, **one strong**
    
- Mastery: 1 ultimate = **no affinity**
    

---

## Affinity relationships  
    
    - str → neutral vs dex, weak vs int
        
    - dex → neutral vs int, weak vs str
        
    - int → neutral vs str, weak vs dex
