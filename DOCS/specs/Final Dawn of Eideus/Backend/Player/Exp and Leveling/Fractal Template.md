## Class/Skills Fractal Template (3×3×7)

### Elements (E1–E7) = the 7 skill slots

- **E1:** Core Skill 1 (Attack) — affinity = core
    
- **E2:** Core Skill 2 (Buff vs weakness) — affinity = core
    
- **E3:** Sub Skill 1 (Neutral vs sub affinity)
    
- **E4:** Sub Skill 2 (Weak vs sub affinity)
    
- **E5:** Cross Skill 1 (Neutral)
    
- **E6:** Cross Skill 2 (Strong)
    
- **E7:** Mastery Ultimate — affinity = null
